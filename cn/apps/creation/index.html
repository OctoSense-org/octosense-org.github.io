03 / IN APP

打开应用，如何使用

  1. 01

    打开文档正常编辑，通过选中段落给 Agent 一个明确的处理范围。

  2. 02

    在原文旁检查改写建议，引用继续保留，变化可以对照查看。

  3. 03

    亲手修改提案，再选择应用或放弃。接受修改后，仍保留撤销路径。

04 / APP CARD

留在桌面，如何使用 App Card

  1. 01

    准备好的改写卡片可以留在桌面，等你处理完其他事再审阅。

  2. 02

    展开即可对比具体段落与提案。回到文档时，仍是同一份草稿和决定状态。

05 / CONTEXT

数据如何关联，为什么有用

仅使用你已接入并允许访问的数据源

文档选区

围绕你选定的段落工作，明确哪些内容需要改变。

引用与研究

保持出处关联，并标出还需要补充来源的论述。

素材与笔记

把获准使用的参考素材带进草稿，不混入无关私人内容。

06 / CONTROL

由你授权的部分

改写只有被应用后才修改文档。导出、发布、分享属于另一个操作，且会明确呈现目的地。

07 / TIMING

Agent 什么时候工作

选区与明确的修改请求触发任务。较长草稿可以在后台准备，再以审阅卡片返回。
