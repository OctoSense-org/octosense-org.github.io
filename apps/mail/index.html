03 / IN APP

Using the application

  1. 01

    Open the unified inbox and choose an account or sender. The original email remains readable alongside any proposed actions.

  2. 02

    Open the school email. An embedded card highlights the old and new pickup times, the source sentence, and an editable reply.

  3. 03

    Revise the reply, inspect the calendar change, then approve. The email and event show the same completion state.

04 / APP CARD

Using the desktop App Card

  1. 01

    A desktop card brings the proposed reply and time change to you without opening Mail. Expand it to inspect the original message.

  2. 02

    Approve once for this event, or allow the defined school-pickup workflow for this sender. Move the card back into Mail without losing edits.

05 / CONTEXT

How the context connects

Only the sources you have connected and allowed

Calendar

Match the existing pickup event before proposing a time change; do not create a duplicate.

Contacts & messages

Resolve the sender and related conversation while preserving which account each message came from.

Orders & tracking

A receipt can instead generate a tracking card that follows later dispatch and delivery messages.

06 / CONTROL

What you authorize

A rule names both the sender and the action: school pickup changes plus acknowledgments. It does not authorize other email, and can be revoked. An unrecognized request returns for review.

07 / TIMING

When the agent works

An incoming email triggers analysis. A later message updates the existing proposal or tracking card instead of starting an unrelated task.

08 / TRY IT YOURSELF

Edit a reply. Decide what happens next.

Edit the draft, then choose a single approval or a standing rule. Receive the next message to see how your choice changes what happens.
