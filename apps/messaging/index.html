03 / IN APP

Using the application

  1. 01

    Open the conversation as usual. Keep the original messages, reactions, and participants in view.

  2. 02

    Expand the proposed dinner card beside the relevant messages. Check the time, place, people, and what is still uncertain.

  3. 03

    Edit your acknowledgment or the event details. Confirm before sending a message or adding an appointment.

04 / APP CARD

Using the desktop App Card

  1. 01

    A desktop card combines the proposed reply and event; use its source link to return to the exact conversation.

  2. 02

    If the plan changes, update the existing card. Dismiss or defer it while retaining the conversation.

05 / CONTEXT

How the context connects

Only the sources you have connected and allowed

Mail & contacts

Relate the same person across accounts without mixing the destination of a reply.

Calendar

Check Friday availability and show conflicts before adding dinner.

Navigation

Resolve the shared address into a route and a later departure card.

06 / CONTROL

What you authorize

The card shows the recipient or group before sending. A rule for one contact never implies permission to speak in another conversation.

07 / TIMING

When the agent works

A new message or a change to the agreed plan triggers an update. Unsettled suggestions remain proposals.
